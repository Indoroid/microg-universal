Non-patched companion APKs for the universal microG patch.

| APK | Package | What |
|---|---|---|
| `GmsCompat-Stub-0.0.1.apk` | `app.morphe.gmscompat` | Optional companion: keeps microG alive, one setup notice for all patched apps, status screen (Material 3 / Material You). |
| `MicroG-RE-7.3.2-unofficial.apk` | `app.revanced.android.gms` | MicroG-RE 7.3.2 built unmodified from [MorpheApp/MicroG-RE](https://github.com/MorpheApp/MicroG-RE) source (reports Play services 25.24.32). |

**MicroG-RE here is signed with this project's key, not MorpheApp's.** It cannot update, or be updated by, official MicroG-RE releases, and the stub will show "Unofficial key". Prefer the [official MicroG-RE release](https://github.com/MorpheApp/MicroG-RE/releases/latest) unless you need this exact build.

Patched apps are not included: patch your own APKs with **MicroG support (universal)** (see `morphe/apply.sh`).

Checksums: see `SHA256SUMS`.
